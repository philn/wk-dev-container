# Clangd-indexer deployment

## Containers

Place the `containers/` folder in `~/.config` and then:

```shell
systemctl --user daemon-reload
systemctl --user enable wkidx-server-gtk
systemctl --user enable wkidx-server-wpe
```

The `wkidx-gtk` and `wkidx-wpe` containers are triggered using timers. Place the
`systemd/` folder in `~/.config/` and then:

```shell
systemctl --user daemon-reload
systemctl --user enable wkidx-gtk.timer
systemctl --user start wkidx-gtk.timer
systemctl --user enable wkidx-wpe.timer
systemctl --user start wkidx-wpe.timer
```

The `wkidx-server` containers rely on indexes generated by the `wkidx-`
containers. The servers should be able to reload when the indexes are updated.

Don't forget to open ports on the server, `50051` for gtk server and `50052` for
wpe server.

```shell
sudo firewall-cmd --zone=public --permanent --add-port=50051/tcp
sudo firewall-cmd --zone=public --permanent --add-port=50052/tcp
sudo firewall-cmd --reload
```
